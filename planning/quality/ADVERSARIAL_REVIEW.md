# Final adversarial review protocol

The following lenses were applied by one planning assistant; they are not independent agent reviews. During implementation, assign independent review sessions for material changes, particularly schema, privacy, import, native containment and baseline policies.

| Objection | Required answer / evidence |
|---|---|
| This is the old adjudicator with a new UI | No legacy model/policy/defaults in runtime graph; occurrence/finding/coverage schema |
| The public site only replays a trick | G1 uses File chooser and a different clean control through actual browser readers |
| The amount was inserted by UI filename logic | Source-generated mapping, actual raw outputs, randomized file rename, ordinary adapter path |
| A precise box was guessed from text | API/crop transform chain or explicit page-only/unknown geometry; duplicate fixtures |
| Round-trip math is self-consistently wrong | Independent raster fiducials, not inverse alone; UserUnit build-specific probe |
| Empty or failed OCR looks clean | Typed terminal checks and copy; no missing terminal or all-clear |
| Two engines are treated as truth | No trust probability; same source dependency disclosed; disagreement language |
| A legitimate OCR layer looks malicious | Searchable-scan/white-on-dark controls; structural observations informational |
| Normalization erases a material change | Scalar-map tests preserve all non-whitespace characters |
| The export silently contains a whole PDF | Actual decoded contents preview tests, original default off, hash/source relationship |
| The report phones home or executes HTML | Closed JSON, no ZIP/HTML import, bounded PNGs, no resource URLs, network capture |
| Native imports can run arbitrary commands | Installed allowlist, fixed wrapper argv, explicit source selection; no report commands |
| A parser hang ruins the corpus | Parent process-group kill, atomic per-file output, successful-tail resume |
| The baseline became green by changing itself | Immutable baseline hash and reviewer-approved new file |
| A reduction in coverage is called improvement | Coverage rule fails and categories/denominators retained |
| Browser compatibility is assumed from desktop Chromium | Exact multi-engine/device/AT receipts and truthful unsupported states |
| “Local” is a slogan rather than tested behavior | Cold/warm/offline/deployed canary capture and storage inspection |
| Static assets secretly route through paid compute | No main/bindings/functions, built graph, deployed configuration and request proof |
| Licensing is summarized as everything MIT | Actual binary/font/model notice inventory; PyMuPDF excluded; unknown assets blocked |
| Many forks count as independent evidence | Pinned lineage catalog and explicit inspection/reproduction status |
| A green CI badge hides skipped tests | Nonempty registered commands, skip counts, merged integration rerun |
| Agents weaken tests to satisfy tasks | Protected golden/contract ownership and independent review brief |
| A prepared result is mislabeled after an upgrade | Manifest binds source, reader/build/model/config and report digest |
| A polished screenshot is claimed as product validation | Reference audit separate from G1–G5 implementation gates |

A review receipt must state passed/failed/blocked per objection, with actual artifact paths. It must not merely say “looks good”. New defects return to the owning task or a narrowly scoped repair task and rerun affected integration gates. Do not reopen the product as a SaaS or add a model to conceal a failed boundary.
