## Engineering transfer decisions

Keep the evidence-separation discipline, failure-injection ideas, exact-origin manifests and negative-experiment records. Reimplement geometry, comparison, reader adapters, report contracts and UI for a generic open-world inspector. Reject challenge labels, fee/sponsor decisions, corpus-mode guesses, calibrated adjudication, answer-key handling as output truth, fixed top-third heuristics and closed-menu decoding as a default.

A copied test is copied code: retain its notice. A materially influential idea receives a source reference even if independently implemented. Newly discovered ancestry updates the source and experiment ledgers before merge. A null source commit is a real limitation, never replaced with the submission branch hash as though it pins a separate repository.

## Maintenance cost to expose

Paint/visibility checks require renderer-version fixtures and often approximate compositing; keep native capability labels narrow. OCR retries add transform bookkeeping and latency. Model changes add distribution rights, hash verification, memory and cold-download costs. Geometric restoration adds registration error and false candidates, so it is a report-only experimental branch, not a modification of the PDF. Watchdog and serialization changes affect every successful output and therefore require no-op control tests.
