# Independent review — T52

Review **Close native and regression capability gate** in a different session/person from its implementation author. Read [the worker brief](../workers/T52.md), the canonical task, changed source, input contracts, fixture expectations and actual receipts. A green badge or implementation summary alone is insufficient.

Check unsupported native capabilities and every documented exit-code category.

## Task-specific review

- Baselines never update automatically.
- Stated rules detect regressions and lost coverage.
- The compared versions actually run in separate, recorded environments.
- One failed file cannot erase successful results from other files.
- Reader, source and configuration identities survive report transfer.
- The documented local CI example executes without a hosted account.

Use fixture families F01, F07, F17, F21, F23, F25 and invariants I01, I02, I05, I10, I12, I13, I17. Inspect a negative control and an error/partial path relevant to this task, not only a happy example.

## Scope and integrity

Check that implementation edits stay within `native/tests/gates/`, `artifacts/gates/G3/`, plus the common evidence-only namespaces. Verify approved shared leases, exact contract/dependency identities, complete attribution and no undeclared network or persistence. Reject deleted assertions, unjustified skips, refreshed baselines that hide failure, or tuning on held-out labels. No unrelated SaaS, repair or adjudication code.

## Required disposition

Write `artifacts/tasks/T52/review.md`: reviewed commit, reviewer/session identity, commands actually executed, test counts and skips, source/fixture/model identities, issues with severity and reproduction, and accept/request-changes/blocked. Explicitly label inspection-only areas. A material assertion without evidence is not accepted.

Use the task's proposal procedure for plan conflicts. The integrator repeats affected acceptance on the merge result; branch-local success does not certify integration. Preserve original bytes and rejected-experiment receipts. Rollback reverts candidate changes, never rewrites a baseline to erase a failure.
