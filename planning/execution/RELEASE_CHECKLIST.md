# Final release checklist

This is a required execution checklist, not a claim that the app exists. T55 reviews all items before T54 publication; T54 closes the actual deployment items. Record the exact release-candidate commit and artifact digests next to the completed receipts.

## Product and evidence

- G1 and G2 receipts correspond to the current merged build. Interesting/clean/ordinary-scan own-file flows are real; six gallery cards have real source/readings/manifests and visible preparation labels. Every UI action works.
- Raw strings, normalization maps, duplicate occurrence geometry, source identity, selected scope and incomplete checks survive comparison/export/reopen. No source-text-only fabricated highlight. No all-clear/safety/fraud/adjudication claim or legacy confidence score.
- Browser is useful without native tool/public backend. Native-only checks are visible as unavailable in browser. Mobile/large-file/model failures use the declared profiles and honest partial states.
- G3 receipt proves native/corpus/version-isolated comparison, all documented exit codes, immutable baselines, coverage-loss handling and local CI example. No arbitrary imported profile/plugin execution.

## Quality and trust

- G4 receipt includes actual required unit/property/contract/browser/native/fault/network/visual/accessibility/evaluation/package tests. Required manual AT/device checks are not replaced by a mock screenshot. Required skips fail.
- Clean/damaged metrics have denominator/split/version/environment and thresholds fixed before held-out evaluation. No customer/adoption/revenue quota. All candidate experiments have accepted/rejected evidence, no unnecessary dormant production code.
- Original bytes unchanged; default selected export excludes full PDF/name/notes. Decoded contents equal preview; crops not described as secure redactions. Model cache/document memory and deletion limits accurately documented.
- Actual resolved lock, full action/OCI pins, model/static hashes and SBOM match shipped artifacts. All font/codec/OS/model/adapted-source notices retained. No unknown-rights binary or private Project/user document bundled.
- Reachable critical/high vulnerabilities are fixed or affected feature removed pending a reviewed resolution; no broad unsupported “secure sandbox” claim. Native runtime restrictions are actually tested.

## Repository and presentation

- Separate repository/origin record preserves exact `mib-intake` pin and material influences; original repo unchanged. Real commits/history/reviews/agent interventions, no invented authorship or timestamps.
- README/CLI/examples/offline install/replay commands pass from clean checkout. Capabilities/copy/schema/settings/deployment agree. Claims ledger maps every public claim to current source/receipt, not a planning document.
- Clip labels prepared/live/accelerated portions, shows real own-file and report flow; no private sample data. X/Show HN/case study remain drafts until owner approves publication.

## Static release

- T48 preflight: no Worker main, dynamic routing, SSR, public upload/processing, metered binding or runtime external assets. Asset sizes and model manifests checked. CSP works with actual workers/WASM; no broad unsafe-eval fallback.
- Owner has reviewed account/target, authorized deployment and supplied credentials securely. No secrets/private paths in artifact or logs.
- T54 actual-domain capture verifies static path, headers, correct model versions and no-egress. Account-level Analytics/Zaraz/Rocket Loader injection or paid routes are disabled/not present. Distinguish static request metadata from PDF upload.
- Exact archived release includes source tag, built static assets, native distribution, notices/SBOM, manifests and actual receipts. Rollback to the previous archived static bytes is exercised and documented; release candidate restored. Provider policy/account changes remain an ongoing recheck, not “free forever.”

Finish when these capabilities and receipts exist, not at a calendar date. Any essential missing item blocks release; owner-controlled publication inputs do not block unrelated local implementation.
