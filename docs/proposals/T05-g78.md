and F21 from the frozen catalog. It contains 23 new PDFs and six JSON
scenarios. The manifest now covers 15 catalog families and 45 source entries

F20 sources are JSON inputs to `tests/fixtures/fault_double.py`. The helper
imports no reader, loads no model, and exits within two seconds even without
a supervisor. Its tests impose a shorter deadline and reap each child.
These fixture tests prove the double's behavior, not a production supervisor.

F21's blank PDF is a document-content control. Its consumer must also run the
same actions without any document, as required by the catalog. Crop and report
channels come from the consumer's actual rendered crop and report; no invented
reader report is generated. No PDF contains a URI action or network request.

F19 must never be rendered at an unconstrained scale. The evidence script
computes scale from page dimensions before rendering, caps the long edge at
512 pixels, and records the selected scale. A normal 72-dpi request would
have 10^18 pixels; the PDF itself is below 1 KiB. Production limit-before-
allocation behavior remains the consuming task's responsibility.

The encrypted file uses the public synthetic test credential `fixture`.
It is a load-failure control, not a security recommendation. The malformed
mapping intentionally produces different reader behavior: consumers retain
raw API output, missingness, or failure rather than substituting a label.

repository's frozen native dependency versions. This evidence does not claim
native adapter acceptance, browser behavior, OCR results, or no-egress proof.
No engine OCR/model initialization, corpus, performance run, or host change
was performed. No dependency was installed.
