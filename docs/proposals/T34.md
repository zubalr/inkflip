# T34 proposal: activate test:regression and native baseline tests

## Observed source

T34's effective command is:

`bun run test:regression && uv run --project native python -m pytest native/tests/baselines -q`

`config/acceptance-commands.json` currently lists `test:regression` as
`declared` with `argv: null`. `allowed_scope` names `tests/regression/` but
the command also requires `native/tests/baselines/`.

The registry file notes T01/T02 ownership of the command manifest. T34 is the
`owner_task` of `test:regression`.

## Recommended correction

- Activate `test:regression` with `node --test tests/regression/regression.test.mjs`
  and `collection: structured-report`.
- Treat `native/tests/baselines/` as T34 test scope implied by the command.

No schema or lockfile change. Continue the independent T34 suite in this
worktree.
