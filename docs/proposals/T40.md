# T40 proposal: hashed wheels and live container runtime

## Observed source

The planning recipe `planning/deployment/examples/Dockerfile.native` copies
`native/dist/` and `release/native-requirements.lock`. Those artifacts are
T47 distribution outputs and are absent from this checkout.

Docker CLI exists; the OrbStack daemon socket is not running. Starting that
VM is out of scope for this allocation.

## Minimal reproducer

```sh
ls native/dist release/native-requirements.lock
docker info
sh scripts/run_native_container.sh --source-root fixtures/public --out /tmp/inkflip-out -- inspect /input/mapping-control.pdf --out /output/r.json
```

## Recommended correction

- T47 publishes hashed wheels and the lock copied by `build/native/Dockerfile`.
- A host with an approved running engine then executes
  `scripts/run_native_container.sh` against owned synthetic PDFs and records
  the image digest. Until then the container no-network criterion stays blocked.
