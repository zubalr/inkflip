# T35 proposal: upgrade-rules path

`planning/deployment/examples/reader-upgrade.sh` refers to
`quality/upgrade-rules.json`. That path is outside T35 allowed_scope.

The owned, generated rules used by the runnable example are
`examples/reader-upgrade/upgrade-rules.json`, produced from the public
mapping fixtures (`$100` / `$1,000` expected text, required_coverage,
stable_reading) with `fail_on_coverage_loss` and `fail_on_error`.

Copying the same file into `quality/` needs the shared-owner decision.
