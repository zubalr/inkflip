# T46 proposal: shared manual-receipt checker

## Observed source

T46's effective command is:

`node --test tests/parity/*.test.mjs && python scripts/check_manual_receipts.py compatibility`

`scripts/check_manual_receipts.py` did not exist. The same command name is
also T37 (`accessibility`) and T53 (`release`). The file sits outside
T46 `allowed_scope`.

## Minimal reproducer

```sh
python scripts/check_manual_receipts.py compatibility
```

## Proposed patch

A small shared checker that reads `docs/compatibility/manual-receipt.json`
for `compatibility` and fails closed for other kinds until their owners
add receipts. T46 landed that script so the effective command is executable;
coordinator/T01 should confirm the shared-script lease.
