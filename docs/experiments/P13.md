# P13 Experiment Report: Native RapidOCR Complement Evaluation (T44)

## Executive Summary
- **Experiment ID**: P13
- **Task ID**: T44 (pdf-t44)
- **Status**: `blocked` (baseline measured; candidate blocked due to missing package and unbundled model weights under offline containment)
- **Disposition**: `blocked_missing_dependency_and_weights`
- **Recommendation**: Maintain Tesseract as the sole native OCR engine. RapidOCR remains `default_not_installed` due to unbundled PP-OCRv5 mobile English ONNX weights and missing dependencies under offline containment.

## Evaluated Mechanisms
1. **Baseline**: Native Tesseract OCR (v5.5.3).
   - Evaluated across 8 development fixtures spanning F14 (`native-unicode`), F15 (`ocr-material`), and F16 (`adjacent-crop`) loaded from `fixtures/manifest.json`.
   - Renders 2.0x rasters deterministically via PDFium and persists raw PNG rasters into `artifacts/P13/rasters/` for persistent auditability.
   - Captures real execution timings (~0.05s–0.12s per fixture), exact raster pixel dimensions, and raw OCR output.
   - Nonzero exit codes, timeouts, and missing binaries are strictly preserved as terminal failures in the denominator rather than silently converted to empty text completions.
2. **Selected Candidate**: RapidOCR v3.8.1 with PP-OCRv5 mobile English configuration (Source S47).
   - Package audit: Pinned version requirement `rapidocr==3.8.1`; `rapidocr` and `rapidocr_onnxruntime` are not installed in the native Python environment.
   - Weights audit: Target PP-OCRv5 mobile English models (`en_PP-OCRv5_mobile_det.onnx`, `en_PP-OCRv5_mobile_rec.onnx`) are not pre-bundled in the repository checkout.
   - Model binary validation: Enforces ONNX protobuf header verification (`is_valid_onnx_model`). Dummy text files (e.g. counterexample containing `"not an ONNX model"`) fail binary validation and trigger `candidate_rejected_corrupted_weights`, preventing unverified candidates from being marked available.
   - Containment policy: Runtime network downloading is forbidden under repository offline security invariants (I13/I14). Attempted preparation (`uv pip install --project native rapidocr==3.8.1`) and model downloads are recorded with offline containment error.
   - Result: Concrete environment blocker recorded as `blocked_missing_dependency_and_weights` without fabricated execution or simulated rejection.
