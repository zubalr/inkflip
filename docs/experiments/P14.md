# P14 Experiment Report: Original-Preserving Geometric Raster Evaluation (T45)

## Executive Summary
- **Experiment ID**: P14
- **Task ID**: T45 (pdf-t45)
- **Status**: `completed`
- **Disposition**: `rejected_experiment`
- **Recommendation**: Formally reject geometric raster resampling and deskew transforms from the production pipeline. Resampling crisp, axis-aligned document rasters introduces anti-aliasing blur and subpixel coordinate drift, corrupting clean ruled controls. The production pipeline must preserve unmodified canonical rasters; automated sanitization or geometric mutation is prohibited.

## Evaluated Mechanisms
1. **Baseline**: Unmodified canonical rendering.
   - Renders original PDF pages at 2.0x scale (~150 DPI) deterministically via PDFium.
   - Preserves exact vector edge definitions, 1-pixel rules, and native font glyph bounds.
   - Canonical rasters are immutable once generated (Invariant I02).
2. **Selected Candidate**: Bounded affine deskew / strip-registration transform with inverse chain.
   - Applies bounded rotation / deskew with bilinear resampling to straighten text.
   - Invertible affine transform chain recorded for source attribution (Invariants I16, I17).
   - **Fatal Clean-Control Corruption**: When applied to clean, already-aligned documents with ruled forms (e.g. `ocr-material-control.pdf`, `partial-clip-control.pdf`, `huge-page-control.pdf`):
     - **Resampling Blur**: High-frequency edge variance degraded across all clean controls (mean edge variance loss: > 3.0%), softening sharp boundaries.
     - **Subpixel Coordinate Drift**: Quantization on intermediate pixel grids produced subpixel rounding errors (up to ~0.35 px drift) upon inverse roundtrip mapping.
     - **Clean Rule Corruption**: 1-pixel stroked borders and ruled table lines were anti-aliased into multi-pixel grey bands, violating clean form registration.

## Architectural Conclusion
The acceptance criteria explicitly stipulate:
1. `Any lost registration or clean corruption rejects`
2. `gain must transfer beyond the challenge generator`
3. `no generic reconstruction/search or PDF write path`
4. `negative result closes task with deleted production candidate.`

Because resampling clean, axis-aligned controls induces measurable pixel blur and subpixel coordinate drift, the candidate fails the mandatory negative controls. The candidate is **rejected**. The application must continue to inspect original rendering outputs directly without automated geometric warping or repair.
