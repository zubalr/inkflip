# P09 Experiment Report: Paint-Order and Ink-Counterexample Evaluation (T41)

## Executive Summary
- **Experiment ID**: P09
- **Task ID**: T41 (pdf-t41)
- **Status**: `completed`
- **Disposition**: `rejected_heuristic_recommendation`
- **Recommendation**: Reject general rectangular-ink heuristics and universal visibility oracles; maintain explicit PDF text object render modes (`Tr`) and distinct reader observations, keeping complex compositing unavailable until full renderer state tracking is proven.

## Evaluated Mechanisms
1. **Metadata-Only Baseline**:
   - Inspects text render mode `Tr` directly from PDF content streams.
   - Accurately identifies `Tr == 3` (neither fill nor stroke text = invisible).
   - **Failure Modes**: Misses white-on-white text (`F04 white-contrast-white`) and text occluded by subsequent opaque fills (`F05 paint-order-after`), achieving 66.7% precision with 2 false-visibility classifications on invisible controls.
2. **Rectangular-Ink Heuristic**:
   - Renders page rasters via PDFium and measures pixel contrast / thresholded dark pixels within the text occurrence bounding box.
   - Detects white-on-white text absence and occluded text in simple backgrounds.
   - **Fatal Counterexample (F24)**: On `overlap-ink-invisible.pdf`, invisible text (`Tr == 3`) has its bounding box crossed by an unrelated stroked border. The heuristic observes border ink inside the text rectangle and falsely asserts visibility (precision 80.0%, 1 false visibility on hard invisible control).
3. **Bounded Paint-Order Candidate**:
   - Combines object render mode `Tr`, fill color contrast against background fills, operator paint order with 2D axis-aligned geometric bounding-box occlusion calculation, and path clipping bounds.
   - Achieves **zero hard-control false visibility** (precision 100%, 0 false visibilities).
   - Honestly flags non-rectangular clipping (`partial-clip-triangle.pdf`) and partial occlusion (`partial-clip-partial.pdf`) as `unsupported_compositing` rather than guessing (decision coverage 77.8%, 2 abstentions).

## Architectural Conclusion
The rectangular-ink heuristic is rejected due to proven counterexamples where unrelated drawing elements cross text bounding boxes. While the bounded paint-order candidate eliminates hard-control false visibility on synthetic controls, full PDF graphics state (blend modes, transparency groups, complex soft masks) is not generally solvable without a complete rendering engine. Production pipelines must not promote heuristic visibility claims to ground truth. Raw reader observations remain the standard.
